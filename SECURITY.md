# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability or network issue within Wobbly Bottle, please do not disclose it publicly. Contact the maintainer directly through GitHub Security Advisories or by contacting support via our [Official Website](https://61mertkoc-cpu.github.io/wobbly-bottle/).
